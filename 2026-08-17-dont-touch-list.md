## ManyChat setup (do before posting)
This CTA needs a "comment keyword → auto-DM" flow live on the actual post before it goes up, or comments will pile up with nothing sent back. In ManyChat:
1. **Automation → Instagram → Comment Growth Tool** (sometimes called "Comments Automation").
2. Create a new automation, select **this specific post** once it's live (you attach it after publishing, not before).
3. Set the trigger keyword to **CLOSE** (case-insensitive, "contains" match so "CLOSE!" or "close please" still fires).
4. Public reply: something like "Sent! Check your DMs 📩" (comment-reply is required by Instagram/ManyChat rules before the DM step).
5. DM step: attach **dont-touch-list-card.png** directly as an image in the message (upload it into that flow step), plus a short line like "Here's your Don't-Touch List — save this before you get preapproved."
6. Turn the automation **ON** and test it yourself by commenting CLOSE on the live post before sharing it further.
